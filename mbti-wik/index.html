第一站02 / 理論的骨架

從態度與功能，看見理論的骨架

第二站03 / 從理論到量表

四組偏好，十六種組合

依本文說明，MBTI 以簡明自陳反應呈現個人在知覺與判斷方面的基本偏好。

E / IS / NT / FJ / P

文章將四組偏好組合成十六種類型，作為理解類型理論的一種方式。

文章提醒

偏好像連續線的兩端

每個人都會運用兩端傾向，只是較偏向其中一端；文章並指出類型沒有長短優劣。

每個人都會運用不同傾向，只是慣常偏好有所不同。

來源：Wiki 文章整理頁。

偏好，如何遇見學習情境？

文章舉例整理不同面向可能偏好的課堂活動：

第四站05 / 偏好與學業

偏好、興趣與學業

文章轉述的預測涉及：

  • 學業表現與性向、勤勉、興趣等面向相關。

  • 多元策略讓學習者發揮不同長處。

把故事收回來06 / 文章的教育結語

不把地圖變成界線

作者主張類型不是決定論：學生可以練習不偏愛的策略，教師可以把偏好作為教學參考。

重點是認識偏好、擴展策略，依情境調整。

依據：楊淑晴（1999）文章整理與Wiki 概念頁。

旅程的收尾08 / 心理類型與學習

一張開放的學習地圖

榮格的心理類型理論描繪人們認識世界、作出判斷的不同偏好；Myers 與 Briggs 將這些概念整理為 MBTI，讓個人有一套理解類型的語言。

楊淑晴（1999）進一步介紹這些偏好如何呈現在學習活動中。認識偏好能幫助學生發揮長處、拓展策略，也讓教師以更多元的方式設計教學。

認識自己的偏好，是拓展學習方式的起點。
