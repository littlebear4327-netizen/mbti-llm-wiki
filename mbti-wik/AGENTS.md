# MBTI LLM Wiki 維護規則

本倉庫以 Markdown 維護 MBTI 與人格類型主題知識，並以 GitHub Pages 發布簡報網頁。

## 資料夾

- `raw/`：經確認可保存及散布的原始資料。原始檔唯讀，不覆寫、不改名。
- `sources/`：外部同步參考資料；唯讀。
- `wiki/`：來源整理、概念頁、索引、總覽與維護日誌。
- `notes/`：依 Wiki 撰寫的研究導讀與分析筆記。
- `slides/`：簡報逐頁文稿。
- `html/`：互動式 HTML 簡報原始檔。
- 根目錄 `index.html`：GitHub Pages 首頁。

## 匯入文章

1. 先確認原始檔可保存和散布，再加入 `raw/`；若無法確認，僅記錄書目與可公開來源連結。
2. 讀取來源，建立或更新 `wiki/sources/` 文章整理頁與相關概念頁。
3. 區分來源中的主張、研究結果與 Wiki 的整理推論；重要陳述附上來源或段落定位。
4. 更新 `wiki/index.md`、`wiki/overview.md` 和 `wiki/log.md`。日誌以 `## [YYYY-MM-DD] ingest | 標題` 追加。

## 筆記與簡報

- notes 與簡報的事實主張只使用 `wiki/` 已整理內容；外部候選文獻要獨立標示，納入 Wiki 前不作為論據。
- 保持相對連結有效；若新增、移動或刪除 Wiki 頁面，同步更新索引及引用位置。
- 維持繁體中文、清楚標示文獻依據，避免將人格類型當成診斷或固定能力判斷。
- 更新網頁時同步確認根目錄 `index.html` 與 `html/` 的簡報內容一致。
