# MBTI LLM Wiki

這是一份可自行上傳至 GitHub 的完整知識庫套件，包含繁體中文 Wiki 維護規則、文章整理、概念頁、notes、逐頁簡報和 GitHub Pages 網頁。

## 發布網頁

將套件根目錄的所有檔案上傳至 GitHub 倉庫根目錄，開啟 **Settings → Pages**，選擇 **Deploy from a branch**，分支使用 `main`、資料夾選 `/(root)`。部署完成後，倉庫的 Pages 設定頁會顯示網站網址。

首頁是 `index.html`；原始 HTML 簡報也保存在 `html/mbti-types-overview/`。MathJax 由 CDN 載入，LaTeX 公式顯示需要網路連線。

## 內容

- `AGENTS.md`、`wiki/AGENTS.md`：根目錄及 Wiki 維護規則。
- `wiki/`：索引、總覽、來源整理、概念頁與日誌。
- `notes/`：研究導讀筆記。
- `slides/`：逐頁簡報內容。
- `html/` 與 `index.html`：手帳風互動簡報。
- `raw/README.md`：原始資料散布說明。

## 原始文章

此套件未收錄原始文章 PDF 或全文整理稿，以免在未確認散布權利前公開傳播。原始文章書目及公開書目頁連結保留在 Wiki 來源整理頁；若你確認擁有公開散布權，可自行加入原始檔並更新相關連結。
